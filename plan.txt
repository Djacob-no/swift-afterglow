Swift Afterglow — Implementation Plan
Research brief for the coding agent. Researched 2026-11-02 ~09:30 Oslo (UTC+1). Domain facts and data locations only; implementation choices are yours.

1. Goal & success criteria
A static 3D site honouring NASA's Neil Gehrels Swift Observatory (NORAD 28485, COSPAR 2004-047A, launched 2004-11-20 17:16 UTC) as it reenters. Users get three things: (a) a celestial sphere where Swift's ~2,046 GRBs flash in chronological order, (b) a live dot showing Swift's decaying orbit around a 3D Earth with a reentry countdown, and (c) a memorial mode after reentry. Done when: it is live on Cloudflare Pages by Tue Nov 3 evening (Oslo), loads in under 3 s on 4G, runs at 60 fps on a mid-range phone, every number shown traces to a cited source, and the memorial switch works without a redeploy.

2. Name
"Last Light" is already in use: https://tohuvavohu.com/swift-last-light/ ("Swift · Last Light — Catch the last light", a pass-finder with reentry forecasts). Don't use it.
Recommended: "Swift Afterglow". In GRB science an afterglow is the fading X-ray and optical glow that Swift's XRT and UVOT chased, so the name fits the mission and the memorial theme. Loose checks: swiftafterglow.com and .app didn't resolve, which suggests they're unregistered (not verified with a registrar). afterglow.watch resolves to an unrelated site. A GitHub repo search for "swift afterglow grb" found no clash.
Alternates: "2,046 Flashes" (the count) or "Swift: Last Burst".
Credit the "Last Light" page and link to it as a companion tool.
3. Domain context (verified live)
Status

NASA, 2026-10-23: Swift reached 275 km on Oct 20, entered safe mode, and Penn State ended operations. The servicing mission "ended in August without an attempt to boost." https://science.nasa.gov/blogs/swift/2026/10/23/nasas-swift-mission-ends-ahead-of-re-entry/
Rescue: Katalyst Space's LINK (launched on Pegasus XL) did not capture or boost Swift. SatNews (2026-11-01) says attitude-control anomalies stopped proximity ops within about 15 km. https://satnews.com/2026/11/01/nasas-swift-observatory-expected-to-burn-up-in-atmospheric-reentry-following-failed-commercial-rescue/

4. Data pipeline (prebuild everything; neither source sends CORS headers)
GRBs

Index: https://swift.gsfc.nasa.gov/archive/grb_table/
The "fullview/" page generates a TSV at /archive/grb_table/tmp/grb_table_<id>.txt. The tmp URL is ephemeral, so scrape the link from fullview/ at build time.
Commit a snapshot as well, as a fallback.
No Access-Control-Allow-Origin header, so client-side fetching won't work.
TSV contents (2026-11-02 snapshot)

35 tab-separated columns, 2,046 rows, from 041217 to 261017A.
Columns:
GRB, Time[UT], Trigger#
BAT RA/Dec (J2000, decimal degrees), BAT error (arcmin), T90 (s), fluence 15–150 keV (1e-7 erg/cm²), 1-s peak flux, photon index ("1.09, PL"/"CPL")
XRT RA/Dec (sexagesimal strings), error (arcsec), fluxes, NH
UVOT RA/Dec (sexagesimal), magnitudes
Other observatories, Redshift, Host, Comments, References (GCN numbers), Burst Advocate
Dates come only from the name: YYMMDD plus a letter.
Missing values

Missing values appear as n/a or empty.
BAT RA is missing on 18 rows. T90 is n/a or empty on about 408 rows.
Redshift is present on only 467 rows, as free text with several values, e.g. 8.0 (MPI/ESO: photometric)|~8.1 (TNG) and 6 < z < 8 …. Parse the first numeric value, keep the raw text, and flag photometric vs spectroscopic.
Positions

Use the best available position: UVOT > XRT > BAT.
Keep the error radius so the visual can show it.
Curated highlights (all values below verified in the table)

221009A "BOAT": 2022-10-09 14:10:17 UT, T90 1068.4 s, fluence 740, z 0.151.
090423: z ≈ 8.0–8.1 photometric. The table only gives the photometric value. Cite literature (Tanvir+ 2009, z≈8.2) separately.
050904: z 6.29.
130427A: z 0.34.
Also consider: 080319B "naked-eye burst"; 170817A (GW counterpart — Swift follow-up, not a BAT trigger, so check); 060614. These are not yet verified against the table.
TLE

URL: https://celestrak.org/NORAD/elements/gp.php?CATNR=28485&FORMAT=TLE (or FORMAT=JSON for OMM).
No CORS header was returned.
The latest epoch was 26305.93, i.e. 2026-11-01 ~22:16 UTC. Mean motion was 16.204 rev/day (≈210 km); Last Light reports altitude 212 km.
CelesTrak refreshes roughly every few hours. Don't poll more than about once every 2 h, or it may block you.
Use a Cloudflare Worker cron (every 1–2 h) to fetch the TLE into KV/R2 and serve /tle.json with CORS. Alternatively, trigger a scheduled rebuild with a GitHub Action.
SGP4 accuracy

At about 200 km with ndot ≈ 0.019, along-track error grows by tens of km to hundreds of km within hours.
Show the TLE epoch and its age, and draw the dot as an uncertainty arc that grows with time since epoch.
Stop propagating if the propagated altitude falls below about 120 km, or if the TLE age is over 12 h near the window.
Never claim a location for the reentry.
Predictions

Aerospace returned HTTP 403 to automated fetches (per Last Light). Keep predictions in a hand-edited predictions.json, with source, issued, epoch, and window per entry.
5. Data model (high level)
grbs.json (~150–250 KB gzipped; aim for compact arrays): id, ISO time, ra, dec, posSource and error, t90, fluence, peakFlux, z (number|null) plus zRaw, xrtDetected, uvotDetected, otherObs, gcnRefs, advocate.
highlights.json: id, title, one-line blurb, source URL.
predictions.json: as described in §4.
/tle.json (live): line1, line2, epoch, fetchedAt.
status.json: mode ("live" | "memorial"), reentryTime (null | ISO), source URL.
6. Product / UX
Intro: start black, then show one flash, then "Swift saw 2,046 of these." Then pull back to Earth and the sphere.
Live mode: Earth with Swift's dot, its trail, and the uncertainty arc. Show a countdown to the earliest plausible window edge and to each source's center time, a prediction-band chart, and the TLE age.
Memorial mode: the dot is removed. Show "2004-11-20 → <reentry date>" and a full timeline replay. Add a link to NASA's statement.
Timeline: a scrubber from 2004-12-17 to 2026-10, with play/pause and speed control. Each burst flashes at its position; flash size follows log fluence and decay follows T90. Show a year label and a running count.
Burst detail (on click or tap): name, date, coordinates, T90, fluence, z, which instruments detected it, and links to GCN circulars (https://gcn.nasa.gov/circulars/<n>). Also offer filters: long vs short (T90 < 2 s), and "has redshift".
Mobile: tap targets, a bottom sheet for details, and a reduced point budget/DPR.
Share: a static OG image of the sky plus Earth, and a URL hash for each burst (#grb=221009A).
Audio (optional, off by default): a soft tone per burst, with pitch from z.
7. 3D / visual guidance (domain conventions)
Convert RA/Dec (J2000, ICRS ≈ J2000 for this purpose) to unit vectors: x=cosδcosα, y=cosδsinα, z=sinδ, in an equatorial frame with +z toward the celestial north pole. Map this to three.js's y-up convention consistently.
Earth's rotation: the Greenwich meridian angle in the equatorial frame is GMST (satellite.js gstime). Keep the sky static and rotate Earth by GMST.
satellite.js eciToGeodetic returns TEME coordinates. TEME vs J2000 is negligible for this visual.
Sun direction (for the day/night terminator and sunlit status) is a simple low-precision formula.
Star background, optional:
HYG v4 (astronexus, CC BY-SA 4.0 — attribution and share-alike apply to the derived data).
Yale BSC5 (public domain-ish, ~9k stars; check the current HEASARC/CDS terms).
Use only magnitude < 6.5 for size.
Earth textures: NASA Blue Marble / Black Marble from NASA Visible Earth. These are NASA imagery, generally not copyrighted; credit "NASA Earth Observatory".
Overlay faint galactic and ecliptic lines for context. GRBs are isotropic, which is itself worth a caption.
